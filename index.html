02 / CONNECT↗

Connect the local gateway.

Available on PyPI as furox-scientific-toolkit-mcp 0.2.0. Python 3.10+ and an MCP-capable client are required. Install individual upstream research packages separately when needed.

python -m pip install furox-scientific-toolkit-mcp
python -m scientific_toolkit_mcp
